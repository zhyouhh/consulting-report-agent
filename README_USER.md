# 咨询报告写作助手 - 使用说明

## 简介

这是一个面向内部同事的 Windows 桌面客户端，用来推进咨询报告写作。

## 系统要求

- Windows 10/11
- 解压后直接双击即可使用

## 首次使用

1. 双击 `咨询报告助手.exe`
2. 程序会自动打开桌面窗口
3. 默认显示 `试用通道`
4. 如果试用通道可用，可以直接开始写

## 连接模式

### 试用通道

- 仅供快速试用，无服务质量承诺
- 推荐有条件使用自定义 API
- 默认模型：`deepseek-v4-pro`

### 自定义 API

- 高级模式
- 适合已经有自己 API 的同事
- 可在设置里自行填写地址、密钥和模型

## 创建项目

点击左侧 `新建报告` 后，填写：

- 工作目录
- 项目类型
- 报告主题
- 截止日期
- 预期篇幅
- 初始材料（可选）

## 工作流程

1. 新建项目
2. 在中间聊天区和助手讨论需求
3. 在右侧工作区查看当前阶段和项目文件
4. 需要时触发独立审查
5. 导出 `可审草稿`

写正文阶段可以直接对助手说「这里配个图」「画个流程图」「把这组数字画成折线图」，助手会生成图表插进报告正文；图表在文件预览里直接可见，导出的可审草稿里也会带上。

正文修改或覆盖前会自动保留近期版本；需要撤回时，直接告诉助手列出草稿版本并恢复指定版本。

## 当前导出说明

- 当前支持导出 `可审草稿`
- 导出的文档自动带封面、目录、页眉页码和标准中文排版（正文宋体、标题黑体）
- 在 Word/WPS 中打开时如果提示「是否更新此文档中的域」，选「是」，目录页码会自动生成
- 这是给内部审阅和继续修改用的，不是最终定稿排版版本
- 不需要在电脑上单独安装 Pandoc

## 数据存储

- 配置文件：`C:\Users\你的用户名\.consulting-report\users\local\config.json`
- 项目文件：`C:\Users\你的用户名\.consulting-report\users\local\projects\`

## 常见问题

**Q: 试用通道不能用怎么办？**  
A: 先打开设置，确认仍是 `试用通道`；如果试用通道暂时异常，可以切到 `自定义 API`。

**Q: 程序无法启动？**  
A: 先检查是否被杀毒软件拦截，必要时添加信任。

**Q: 项目文件保存在哪里？**  
A: 在 `C:\Users\你的用户名\.consulting-report\users\local\projects\项目名称\`。
